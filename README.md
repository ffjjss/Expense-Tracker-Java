# ExTra — Personal Expense Tracker

A Java Swing-based desktop application for managing personal expenses — built to practice Java, OOP, and GUI development.

## Features
- Add expenses with date, category, description, and amount
- View all expenses in a table
- Track total spending, number of expenses, and average expense
- Search expenses by category
- Delete selected expenses
- View spending summaries by category
- User-friendly dark-themed GUI

## Tech
- Java
- Java Swing
- Java AWT
- Built and run in IntelliJ IDEA

## What I learned
Building this project helped me practice Java OOP concepts, Swing GUI components, event handling, tables, collections, and organizing data within a desktop application.
